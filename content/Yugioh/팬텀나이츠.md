### 응용: 사천의 용 ② 활용 (상대 턴)
- 사천의 용 ②: 상대가 효과를 발동했을 때 소재 1개를 떼고, **어둠 속성 랭크4 엑시즈**를 사천의 용 위에 겹쳐 엑시즈 소환 취급으로 특소
- 벨즈 오피온·엑소시스터 카르마엘은 원래 전용 소재가 필요하지만, 이 방법이면 소재 조건 없이 꺼낼 수 있음
- **벨즈 오피온**: 소재가 있는 한 서로 레벨5 이상 특소 불가 → 상대 대형 몬스터 전개 봉쇄
- **엑소시스터 카르마엘**: 상대가 몬스터 효과·일반 마법·일반 함정을 발동했을 때, 소재를 전부 떼고 그 효과를 "상대가 자기 묘지 카드 1장을 패에 넣는 효과"로 바꿈 → 사실상 무효급 방해
  - 사천의 용 ②로 겹쳐 나오면 소재가 있으므로 바로 다음 상대 효과에 사용 가능
- 흐름 예시: 상대 턴 럼팬포로 사천의 용 등장(① 파괴) → 상대가 효과 발동 → 사천의 용 ②로 카르마엘/오피온 겹쳐 소환 → 카르마엘로 다음 효과 방해

## 용사 엔진 (아라메시아의 의)

### 제약 정리
- 아라메시아를 발동하는 턴: **특수 소환된 몬스터 이외의 필드 몬스터 효과 발동 불가** (턴 전체 적용)
- ✅ 사용 가능: 패·묘지 효과 전부, 특수 소환된 몬스터의 효과 (사이스·바르디시·브스·특소된 디케이·티어 등)
- ❌ 사용 불가: **일반 소환한 몬스터의 필드 효과** → 일소 몬스터 효과를 먼저 쓰면 그 턴 아라메시아 발동 불가
- 일반 소환은 효과 없이 소재용으로만 사용 가능

### 엔진 기본 흐름
아라메시아 → 용사 토큰 특소 + 덱에서 운명의 여로 배치 → 여로 ①: 그리폰라이더 서치 후 **패 1장 버림** → 그리폰라이더 자체 특소 → 여로 ②: 드라코백 서치 또는 토큰에 장착
- 결과: 그리폰라이더(효과 무효 1회) + 토큰 + 드라코백(바운스)

### 섞을 때 주의
- 둠솔 ①(패에서 특소)은 필드에 몬스터가 없어야 함 → **토큰이 나오기 전에** 사용
- 여로 ①의 버릴 카드가 1장 더 필요 → 포그블처럼 묘지에서 쓰는 카드를 버리면 손해 없음
- 토큰·그리폰라이더가 몬스터 존 2칸 차지 → 마무리 조정 필요
- 엔진과 못 쓰는 루트: ③ 둠솔 루트(티어 일소 효과 사용), 데스가이드 루트(일소 효과 사용)

### 루트 A: 어매 + 아라메시아 + 버릴 카드 1장
1. 어매 → 로브 묘지로 → 묘지 로브 제외 → 둠솔 서치
2. 둠솔 특소 (필드 비어 있을 때) → 베일 세트·발동·특소
3. 둠솔 + 베일 → 사이스 → ① 디케이 특소 → 디케이 ② 부츠 서치 → 부츠 특소
4. 디케이 + 부츠 + 사이스 → 바르디시 → ① 티어 묘지로 + 럼퀴엠 세트
5. 묘지 부츠 제외 → 포그블 서치 / 티어 자기 소생
6. **아라메시아 → 토큰 + 여로 → 여로 ① 그리폰라이더 서치 (버릴 카드 버림) → 그리폰라이더 특소 → 여로 ② 드라코백**
7. 티어 ① (포그블 버림) → 글로브 묘지로 → 묘지 포그블 제외 → 글로브 특소

## 메모
- 10월 금제: 금지 카드 없음. 어매·증원·증G·드롤·리틀나이트 제한, 우라라·도미나스 준제한 매수 적합.
- 원본 전개 정리에서 고친 부분: ①의 "사이스 효과 디케이클록 서치"는 **서치가 아니라 덱에서 특수 소환** (사이스 ①은 특소 효과). 그래서 디케이는 일반 소환이 아니라 특소로 나오고, 일반 소환권이 남음.
- ③의 5단계: 포그블을 제외하는 순간 티어 ②가 먼저 발동하고, 그 뒤 디케이 소생 → 디케이 ② 서치 순서.
- "필드를 떠나면 제외" 조건으로 소생한 몬스터도 엑시즈 소재로 쓰면 제외되지 않고, 소재에서 떨어지면 묘지로 감 → 브스 ②로 다시 소생 가능.
- 브스 ② 발동 후 그 턴은 어둠 속성만 특소 가능 (덱 엑스트라 전부 어둠이라 문제 없음).
- 데스가이드 루트(일소 → 덱에서 2장째 특소 → 사이스)는 파일 미추가 상태. 필요 시 추가.
