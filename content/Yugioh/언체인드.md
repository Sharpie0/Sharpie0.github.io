## 전개법 (선공)
표기: 일소=일반 소환, 특소=특수 소환 / 소울킹 야마=언체인드소울킹 야마, 라기아=언체인드소울 라기아, 마천 야마=언체인드염 마천 야마, 융합 라크리모사=데먼스미스 라크리모사(융합), 쿠=아=바오 아 쿠

### ① 슈마 1장 (강도 ★★☆)
1. 슈마 일소 → 효과로 덱에서 라키아 특소, 라키아 파괴
2. 묘지 라키아 효과 → 슈야마 특소
3. 슈야마 효과로 슈마 파괴 → 묘지 슈마 효과 → 샤바라 특소
4. 샤바라 + 슈야마로 소울킹 야마 링크 소환 → ① 야마 효과로 아루하 서치 ② 묘지 샤바라 효과로 창도 세트
5. 패의 아루하 효과: 창도를 파괴하고 특소 → 묘지 창도 효과 → 사라마 특소
6. 사라마 효과: 묘지 창도를 세트하고 아루하 파괴 → 묘지 아루하 효과 → 샤라 특소
7. 소울킹 야마 + 샤라로 라기아 링크 소환
8. 묘지 슈야마 효과: 라기아를 파괴하고 특소
9. 동시 처리: ① 묘지 소울킹 야마 효과로 슈마 특소 ② 라기아 효과로 샤바라 회수 ③ 샤라 특소
10. 패의 샤바라 효과: 사라마를 파괴하고 특소 → 묘지 사라마 효과 → 샤바라 특소
11. 샤바라 + 슈야마로 이그제큐티브 시저 엑시즈 소환
12. 샤라 + 슈마로 벨즈뷰트 엑시즈 소환
13. 벨즈뷰트로 레퀴엠 링크 소환 → 효과로 라크리모사 특소 → 라크리모사 효과로 데먼스미스 묘지로
14. 묘지 데먼스미스 효과 (벨즈뷰트를 엑스트라로 되돌리고) 특소
15. 라크리모사 + 데먼스미스로 세퀜티아 링크 소환
16. 세퀜티아 효과: 묘지의 라크리모사 + 레퀴엠으로 융합 라크리모사 융합 소환
17. 융합 라크리모사 효과 → 데먼스미스 특소
18. 융합 라크리모사 + 데먼스미스로 소울킹 야마(2장째) 링크 소환
19. 세퀜티아 + 소울킹 야마로 쿠 링크 소환
- 최종 필드: 쿠, 시저, 창도(세트)
- ⚠️ 1~14단계는 기존 검증 루트, 15~19단계는 다른 검증 루트의 마무리 구간을 이 덱리에 맞게 이어붙인 것(미검증). 쿠의 소재 조건 확인 필요.

### ② 상투스 1장 (강도 ★☆☆) — 이 덱리 그대로 사용 가능
1. 상투스 효과로 토큰 특소 → 토큰으로 레퀴엠 링크 소환 → 라크리모사 특소 → 데먼스미스 묘지로
2. 묘지 데먼스미스 효과 (레퀴엠 코스트) 특소 → 데먼스미스 + 라크리모사로 소울킹 야마 링크 소환 → 슈마 서치
3. 슈마 일소 → 라키아 특소, 슈마 파괴 → 묘지 라키아 효과로 슈야마 특소
4. 슈야마 효과로 슈마 파괴 → 묘지 슈마 효과로 샤바라 특소
5. 샤바라 + 슈야마로 라기아 링크 소환 → 묘지 샤바라 효과로 창도 세트
6. 묘지 슈야마 효과: 창도 파괴하고 특소 → 묘지 창도 효과로 사라마 특소
7. 소울킹 야마 + 라기아로 마천 야마 링크 소환
8. 사라마 효과: 창도 세트, 슈야마 파괴 → 묘지 소울킹 야마 효과 → 묘지 라기아 특소하고 라기아 파괴 → 라기아 효과로 샤바라 회수
9. 패의 샤바라 효과: 사라마 파괴하고 특소 → 묘지 사라마 효과로 슈야마 특소
10. 샤바라 + 슈야마로 시저 엑시즈 소환
11. 엔드 페이즈 마천 야마 효과 → 라기아, 라키아 특소
- 최종 필드: 마천 야마, 라기아, 시저, 라키아, 창도(세트)

### ③ 라크리모사 + 샤바라 또는 아루하 (강도 ★☆☆) — 이 덱리 그대로 사용 가능
1. 라크리모사 일소 → 데먼스미스 묘지로 → 라크리모사로 레퀴엠 링크 소환
2. 데먼스미스 특소 (라크리모사 코스트) → 레퀴엠 효과로 라크리모사 특소 → 소울킹 야마 링크 소환 → 아루하 또는 샤바라 서치
3. 아루하로 소울킹 야마 파괴 특소 → 샤바라로 아루하 파괴 특소 → 묘지 아루하 효과로 슈야마 특소
4. 샤바라 + 슈야마로 라기아 링크 소환 → 묘지 샤바라 효과로 전생 세트 → 전생으로 쌍왕의 계 서치 → 계로 창도 서치 → 창도 세트
5. 묘지 슈야마 효과: 창도 파괴 특소 → 창도 효과로 사라마 특소 → 사라마로 창도 세트, 라기아 파괴
6. 라기아로 샤바라 회수, 묘지 소울킹 야마로 라기아 특소하며 사라마 파괴 → 사라마 효과로 샤바라 특소
7. 샤바라 + 슈야마로 시저 엑시즈 소환
- 최종 필드: 라기아, 시저, 창도(세트) / 패: 샤바라

### ④ 라키아 + 카무라 (강도 ★☆☆)
1. 라키아 일소 → 카무라 효과로 라키아 파괴하고 특소 + 1드로
2. 묘지 라키아 효과로 샤바라 특소 → 샤바라 + 카무라로 소울킹 야마 → 아루하 서치, 창도 세트
3. 이후 ①번 5단계부터 같은 흐름으로 진행
- 최종 필드: ①번과 같음 (쿠, 시저, 창도) + 패: 카무라 드로 1장
- ⚠️ ①번과 같은 이유로 마무리 구간 미검증
