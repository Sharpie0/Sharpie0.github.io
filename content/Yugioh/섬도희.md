## 기본 원칙

### 줄임말
레이·로제=섬도희 레이·로제 / 엘담·스엔·헌영·견신=현람한 ○○ / 인게이지=섬도기동-인게이지 / 링케이지=섬도기동-링케이지 / 앵커=섬도기-위도우앵커 / 렘니스=섬도아식-렘니스게이트 / 제로=섬도희=제로 / TF&TV=The Fallen & The Virtuous / 일소=일반 소환, 특소=특수 소환, EMZ=엑스트라 몬스터 존, EP=엔드 페이즈

### 꼭 지킬 것
- **메인 몬스터 존 비우기**: 인게이지·링케이지·앵커는 메인 몬스터 존에 몬스터가 없어야 발동 가능. 섬도희 링크는 EMZ에 두고, 레이·로제·현람 몬스터는 링크 소재로 정리
- **묘지 마법 3장**: 인게이지 추가 드로, 앵커 탈취, 카가리 공격력 등의 조건 → 견신·갑부 고블린으로 채우기
- **링케이지 제약**: 발동 후 그 턴은 EX에서 섬도희만 특소 가능
- **현람 몬스터 특소 조건**: 내 묘지에 싸이크론이 있거나, 상대 필드에 마함이 없을 때

### 운영 방향
- 섬도희는 한 번에 막는 덱이 아니라, **상대 움직임을 보면서 방해를 하나씩 끊어 쓰는 덱**. 상대 턴이 끝나면 내 필드가 거의 남지 않는 게 정상이고, 대신 상대 손패·리소스를 깎아서 다음 턴에 정리하는 흐름
- 가장 큰 약점: **제로 ② (릴리스)에 우라라·와라시를 맞는 것**. 레이·로제 특소, 파괴, 렘니스 ② 링크 연계가 한 번에 끊기고 다음 턴 리소스까지 사라짐 → 제로 ② 발동 전후로 상대 패트랩 매수를 의식
- 인게이지 1장으로 시작할 때는 **호넷비트보다 레이를 서치**하는 편이 증G에 덜 아픔 (레이는 일소 전에 증G를 확인할 수 있음) → 호넷 미채용인 이 덱과 잘 맞음
- 렘니스는 선공에서는 꼭 서치하지만 **후공 돌파에는 거의 도움이 안 됨**

## 전개법 (선공)

### ① 레이 1장
1. 레이 일소 → ① 자신 릴리스 → 제로 특소 (EMZ)
2. 제로 ① → 앵커 서치
- 최종: 제로 + 앵커 (2방해)
- 증G·후와로스를 맞아도 1드로로 끝나서 **패트랩에 강한 기본 전개**

### ② 로제 1장
1. 로제 일소 → 시즈쿠 링크 소환 (EMZ)
2. EP: 시즈쿠 ② → 링케이지 서치 → 링케이지 발동 (시즈쿠 묘지로) → 제로 특소
3. 제로 ① → 렘니스 서치 → 렘니스 ① 발동 (묘지 링케이지 + 시즈쿠 덱으로)
- 최종: 제로 + 묘지 렘니스
- 상대 턴: 제로 ②로 1방해 → 나온 레이·로제 중 하나를 아마츠 등으로 바꿔서 묘지 렘니스 ② 발동

### ③ 인게이지 1장
1. 인게이지 → **레이 서치** (호넷 대신)
2. 레이 일소 → ① 카가리 특소 → 카가리 ① 묘지 인게이지 회수
3. 인게이지 → 렘니스 서치 후 세트
4. 카가리 → 시즈쿠 링크 소환
5. EP: 시즈쿠 ② 링케이지 서치 → 링케이지 발동 (시즈쿠 묘지로) → 제로 특소 → 제로 ① 인게이지 서치
- 최종: 제로 + 렘니스 / 패: 다음 턴용 인게이지
- 상대 턴: 제로 ② 파괴 + 렘니스 + 렘니스 ②로 지크 → 3방해
- 주의: 시즈쿠로 가져온 링케이지에 무효(도미나스 임펄스 등)를 맞으면 제로가 안 나옴

### ④ 인게이지 + 레이 (최강 패)
1. 인게이지 → 앵커 서치 (여기서 상대 우라라 확인)
2. 레이 일소 (증G·후와로스 확인) → ① 카가리 → 인게이지 회수
3. 인게이지 → 렘니스 서치
4. 카가리 → 시즈쿠 → EP 시즈쿠 ② 링케이지 서치 → 링케이지 → 제로 → 제로 ① 인게이지 서치
- 최종: 제로 + 렘니스 + 앵커 / 묘지 섬도 마법 2장 / 패: 인게이지 + 나머지 3장
- 제로가 날아가도 리소스와 방해가 남고, 니비루도 비껴 맞을 수 있음

### ⑤ 헌영 1장 (현람 루트)
1. 헌영 → 엘담 서치 → 엘담 특소 → ② 스엔 서치
2. 스엔 특소 → ② 견신 서치
3. 엘담 + 스엔 → 카멜리아 (EMZ) → ① 덱에서 인게이지 묘지로
4. 카멜리아 → 카가리 → ① 인게이지 회수
5. 견신 → 2드로 1버림 → 묘지 마법 3장 확보
6. 인게이지 → 링케이지 서치 + 1드로
7. 링케이지 (카가리 묘지로) → 제로 (공격력 +1000) → 제로 ① 인게이지 회수 → 인게이지 → 렘니스 서치 + 1드로
- 최종: 제로 + 렘니스 / **일반 소환 미사용, 2드로** → 남은 일소로 레이 등 추가 가능
- 공식 DB 현람 섬도희 레시피 루트 기준

## 상대 턴 운영
1. 상대 전개 중 **제로 ②** (릴리스) → 레이 + 로제 특소 → 필드 1장 파괴
2. **레이 ①** → 기본은 **카가리** (묘지 섬도 마법 회수) → 묘지 **렘니스 ②**로 지크 링크 소환 (몬스터 1체 제외)
3. 상대 마함을 처리해야 할 때(필드 마법, 세트 카드 등): 레이 ① → **아마츠** → 어둠 아마츠 + 빛 로제로 **아자레아** → 마함 포함 1장 파괴. 레이 1장에서 아자레아로 가는 길은 아마츠뿐이라 아마츠가 필수
4. **아마츠 ①**: 상대 공격력 2000 이상 몬스터 효과를 "내 섬도희 L 파괴"로 바꿈 → 떠나면 레이 ② 소생으로 이어짐
5. **렘니스 ①**: 묘지 섬도희 몬스터와 섬도 마법을 같은 수만큼 덱으로 → 3장당 1장 바운스

### 방해 카드 쓰는 법
- **앵커**: 몬스터 효과 무효, 묘지 마법 3장 이상이면 엔드까지 탈취 → 탈취한 몬스터를 링크 소재로 처리
- **TF&TV**: 1번째 알비온 코스트로 파괴 → EP에 덱에서 TF&TV 세트 / 2번째 에클레시아 코스트로 파괴 → 에클레시아 ②로 알비온 + 필드 1장 + 자신 덱으로 → 2장으로 최대 3장 제거
- **로제 ②**: 필드 섬도희 L이 내 효과로 떠나면 소생 + 상대 몬스터 1체 무효
- **카멜리아 ②**: 묘지로 가면 상대 필드로 넘어가며 상대 몬스터 1체 묘지로
- **티 폰**: 상대가 EX에서 2체 이상 특소한 턴에 겹쳐 소환

## 후공 운영
- 이상적인 흐름: ① 패트랩으로 상대 전개를 최대한 억제 → ② 내 턴에 섬도 마법(앵커·TF&TV·금지 카드)으로 남은 걸 정리 → ③ 상대 리소스가 바닥난 상태를 만들기
- 섬도희는 **리소스 차이로 이기는 덱이라 한 번에 라이프를 깎기는 어려움** → 레이 1장 원킬 같은 루트는 이론상 가능하지만 실전에서는 잘 안 나옴. 킬각은 상대 필드가 비었을 때 몰아서
- 참고 원킬 (공식 DB 레시피 기준): 레이 일소 공격 → 레이 ① 제로 → 제로 ① 링케이지 → 링케이지로 카가리 → 카가리 ① 링케이지 회수 → 링케이지로 하야테 (누계 8500)

## 사이드 체인지
- 선공: 드로 카드 성격이 강한 **갑부 고블린**을 우선 빼기
- 후공: 느린 **렘니스**를 빼는 것도 고려 (후공 돌파에 약함). 약한 패트랩도 교체 후보
- 참고한 글의 사이드 구성: 아티팩트-롱기누스, 원시생명체 니비루, 응전의 G, 신의 통고 등 → 통고는 제로에 날아오는 우라라·와라시를 막는 용도로도 추천
